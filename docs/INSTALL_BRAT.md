# Installing Quartzo Obsidian Companion via BRAT

Quartzo Obsidian Companion can be installed using the [BRAT (Beta Release Auto-update Tool)](https://github.com/TfTHacker/obsidian42-brat) plugin for Obsidian.

## Prerequisites

1. Install the BRAT plugin in your Obsidian vault
2. Enable the BRAT plugin in your Obsidian settings

## Installation Steps

1. Open the BRAT plugin settings in Obsidian
2. Click on "Add a beta plugin for testing"
3. Enter the following repository URL:
   ```
   https://github.com/olalaurao/quartzo-obsidian-companion.git
   ```
4. Click "Add Plugin"
5. BRAT will install the plugin and enable it automatically

## Version Information

BRAT installs the latest validated GitHub prerelease for this repository. The release artifact version is defined by `manifest.json`, `package.json`, and `versions.json`; do not install from a feature branch or a local build.

## Updates

BRAT will automatically check for updates and notify you when a new version is available. You can update directly from the BRAT plugin settings.

## Troubleshooting

If you encounter issues during installation:

1. Ensure you have a stable internet connection
2. Check that the repository URL is correct
3. Try disabling and re-enabling the BRAT plugin
4. Check the Obsidian developer console for any error messages
